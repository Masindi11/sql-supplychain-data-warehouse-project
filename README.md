# sql-supplychain-data-warehouse-project
Building a supply chain data warehouse with SQL server, including ETL processes, data modeling, and analytics
Supply Chain Data Warehouse

## Project Overview

This project is about building a Supply Chain Data Warehouse using SQL Server. The goal is to collect, clean and organize supply chain data so it can be used for analysis and better business decisions.

## Project Requirements

1. Data Warehouse (Data Engineering)

Objective

Build a data warehouse that stores clean and organized supply chain data for reporting and analysis.

## Specifications

- **Data Sources**: Import supply chain data from CSV files.
- **Data Cleaning**: Find and fix missing values, duplicates and incorrect data.
- **Data Transformation**: Clean and prepare data for analysis.
- **Data Integration**: Combine related data into one central data warehouse.
- **Data Layers**: Use Bronze, Silver and Gold layers to organize the data.
- **Data Modelling**: Create a data model that makes data easier to understand and analyse.
- **Documentation**: Explain the data warehouse structure and the work done in each layer.
2. Supply Chain Analytics (Data Analytics)

####Objective

Use SQL to analyse supply chain data and find useful business insights.

## Areas of Analysis

- **Orders**: Understand order patterns and order performance.
- **Shipping**: Analyse shipping methods and delivery performance.
- **Products**: Identify product performance and demand.
- **Customers**: Understand customer purchasing patterns.
- **Supply Chain Performance**: Find problems and areas where the business can improve.
